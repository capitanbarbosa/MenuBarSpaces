1. From this folder:
   make run

   Installs/updates ~/Applications/ActiveMenuBar.app and opens it.

2. Desktop buttons 1–4 switch Spaces via macOS Space APIs (not keyboard
   shortcuts), so Cursor/Terminal will not eat the clicks.

3. Accessibility is no longer required for switching. Click Spaces to see
   “Space API: ON” and the current desktop index.

4. You need at least 4 Desktops in Mission Control (F3 → add Desktops).

5. Accessibility permission persists across rebuilds because make run signs
   the app with the local "ActiveMenuBar Local Development" certificate.
   On a new Mac, make run creates that certificate automatically. Grant
   ActiveMenuBar Accessibility once after the certificate is first created.

6. Start automatically after macOS login:
   make enable-login

   Check:   make login-status
   Disable: make disable-login
   make enable-login   # turn on
